# New Employee Onboarding Checklist

**Owner:** People Operations  
**Applies to:** All new AcmePay employees

## Before the first day
- Confirm signed offer and start date.
- Create identity account and assign least-privilege access.
- Prepare company-managed laptop.
- Assign a manager and onboarding buddy.

## First day
- Complete identity verification and security training.
- Review the Employee Handbook and Code of Conduct.
- Set up approved communication and ticketing tools.
- Review team responsibilities and escalation paths.

## First 30 days
- Complete role-specific training.
- Review system access with the manager.
- Agree on initial performance goals.
- Confirm understanding of data classification.

## Completion
The manager records completion in the People Portal. People Operations audits overdue onboarding tasks every Friday.
